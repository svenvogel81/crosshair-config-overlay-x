## What is Crosshair-Configurator-X?

Crosshair-Configurator-X targets anyone who needs a reticle overlay they can shape in detail—how it looks, how it responds, and how it fits each setup. Rendering stays external: the tool sits outside game binaries and assets, yet still lets you tune aim markers in a practical way.

It is meant for multi-platform use and any routine where a quick, editable overlay helps. Preset profiles, snappy controls, and multilingual coverage let you keep several reticle layouts organized instead of rebuilding them from scratch.

Configuration lives in profiles so you can keep several reticle variants side by side for different scenarios.

Example profile structure:

{
  "name": "default",
  "reticle": "custom",
  "opacity": 0.85,

  "gradient": true
}

When a build keeps config outside the UI, look in the project data directory or in exported profile files for values you can edit.
